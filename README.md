# وفّر | Waffir 🛒

**مساعد التسوق الذكي ومقارنة أسعار البقالة في السعودية** — تطبيق ويب تقدّمي (PWA) عربي بالكامل، يجمع أسعار المواد الغذائية والمنظفات والأدوات المنزلية من المتاجر داخل مدينتك، يقارنها، يتعلم نمط استهلاكك، ويبني لك قائمة شهرية تلقائية مع توصية بأرخص متجر وأفضل وقت للشراء.

## المزايا

- 🏙️ **مقارنة مقيدة بالمدينة** — كل الأسعار من فروع مدينتك فقط (مكة، جدة، الرياض + اكتشاف تلقائي لمدن جديدة عبر Google Places).
- 🎯 **نظام ثقة بطبقات** — كل سعر يحمل مصدره (فاتورة 99، تقرير مستخدم 90، مجلة معتمدة 95، كشط 80) وتتناقص ثقته مع الزمن، مع شارة حداثة إلزامية بجانب كل سعر.
- 📸 **توثيق بالفاتورة** — صوّر فاتورة ZATCA وسيوثّق التطبيق ٣٠+ سعر رف دفعة واحدة (OCR عربي/إنجليزي + فك رمز QR للتحقق من المتجر).
- 🤖 **قائمة شهرية ذكية** — من تاريخ مشترياتك: وسيط الفواصل والكميات بترجيح أُسّي، تُولَّد قبل يوم تسوقك بثلاثة أيام.
- ✂️ **التقسيم الأمثل** — "كل شيء من متجر واحد: X ر.س" مقابل "التقسيم بين متجرين: Y ر.س (توفير Z)".
- 🛒 **وضع التسوق دون اتصال** — قائمة شطب تعمل offline (طابور IndexedDB يُزامن عند عودة الاتصال) مع إدخال السعر الفعلي الذي يغذي قاعدة الأسعار.
- ⏰ **أفضل وقت للشراء** — كشف دورات العروض المتكررة (≥3 مرات في نفس أسبوع الشهر).
- 🗺️ **اكتشاف المتاجر** — شبكة بحث Google Places لكل مدينة، تجميع الفروع في سلاسل، وتأهيل تلقائي لمصدر الأسعار (API/كتالوج/مجلة) مع استبعاد ما لا مصدر له.
- ⚙️ **خط تحديث يومي** — 8 وظائف مجدولة (تحديث كتالوجات بالفروقات، مراقب مجلات يتعلم يوم النشر، انتهاء عروض، اكتساح قِدم، صحة مصادر، إعادة تأهيل شهرية، توليد قوائم، لقطة KPI) كلها مرصودة في `job_runs`.

## التقنيات

React 18 + Vite + TypeScript + Tailwind (PWA) · Node.js + Express + TypeScript · PostgreSQL + Drizzle ORM · node-cron · tesseract.js (ara+eng) · Vitest + Supertest + Playwright

## التشغيل محلياً

```bash
# 1) المتطلبات: Node 20+ و PostgreSQL 16
createdb waffir

# 2) التثبيت والإعداد
npm install
cp .env.example .env   # عدّل DATABASE_URL و JWT_SECRET

# 3) الهجرة والبذر (183 منتجاً، 6 سلاسل، 3 مدن، مستخدم تجريبي)
npm run db:migrate
npm run seed

# 4) التشغيل (الخادم 3000 + العميل 5173)
npm run dev
```

## النشر على Railway

1. أنشئ مشروعاً جديداً في Railway واربطه بهذا المستودع — ملف `railway.json` يضبط البناء والتشغيل تلقائياً (`npm run db:migrate && npm start`).
2. أضف خدمة **PostgreSQL** من Railway وانسخ `DATABASE_URL` إلى متغيرات الخدمة.
3. اضبط المتغيرات في تبويب Variables:
   - `DATABASE_URL` — رابط قاعدة Railway
   - `JWT_SECRET` — قيمة عشوائية طويلة (مثلاً `openssl rand -hex 32`)
   - `APP_ORIGIN` — رابط تطبيقك (مثل `https://waffir.up.railway.app`)
   - `NODE_ENV=production`
   - `GOOGLE_MAPS_API_KEY` — اختياري، لتفعيل اكتشاف المتاجر الحي
4. للبذر الأولي (مرة واحدة): `railway run npm run seed` أو شغّل `npm run seed` محلياً مع `DATABASE_URL` يشير لقاعدة Railway.
5. الخادم يقدّم واجهة الـ PWA المبنية من نفس الخدمة — خدمة واحدة تكفي.

## تشغيل المحوّلات (الكشط)

- المحوّلات في `server/src/adapters/` خلف وظيفة `catalog-refresh` (يومياً 03:00 أو يدوياً من لوحة الإدارة ← الوظائف).
- محوّل **بنده** يعمل على fixtures (انظر `LIMITATIONS.md` لأسباب الامتثال)، ومحوّل **سلة** عام يعمل على أي متجر سلة مكتشف ومؤكد.
- رفع مجلات العروض: لوحة الإدارة ← رفع مجلة ← اعتماد المستخرجات من قائمة المراجعة.
