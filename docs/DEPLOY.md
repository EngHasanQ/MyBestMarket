# دليل النشر على Railway — تفعيل البيانات الحقيقية والصور

بعد دمج هذا الفرع، اضبط متغيّرات البيئة التالية في Railway ثم أعد النشر:

| المتغيّر | القيمة | الغرض |
|---|---|---|
| `NODE_ENV` | `production` | يفعّل سياسة CSP الصحيحة (تسمح بالخطوط وصور المتاجر) ويُخفي البيانات التجريبية |
| `AUTO_INGEST` | `1` | يجعل التطبيق يزحف كتالوج التميمي الحيّ تلقائياً عند أول إقلاع (≈١٠ آلاف منتج عربي بصور) إن لم توجد بيانات حقيقية |
| `SHOW_DEMO_DATA` | `false` | (افتراضي في الإنتاج) يعرض فقط البيانات الحقيقية المستوردة |
| `GOOGLE_MAPS_API_KEY` | (اختياري) | لم يعد مطلوباً — الاكتشاف يتم مجاناً عبر OpenStreetMap تلقائياً عند الإقلاع |

> **اكتشاف المتاجر مجاناً (بلا مفتاح):** عند الإقلاع يكتشف التطبيق فروع المتاجر في
> مدن المستخدمين عبر OpenStreetMap (بنده، العثيم، بن داوود، النوري، الراية، لولو،
> الدانوب، كارفور، هايبر الوفاء/الأبراج…). أسعار التميمي تأتي آلياً؛ بقية السلاسل
> تُملأ برفع مجلات عروضها (PDF) من لوحة الأدمن — يقرأها الخط بالمسح البصري ويقصّ
> صور المنتجات كأدلّة.

> بعد أول نشر بـ `AUTO_INGEST=1`، يبدأ الاستيراد في الخلفية (دقائق). راقب السجلّات
> («بدء الاستيراد الحيّ التلقائي»). الصور تُشار من مصدرها مباشرة (CDN التميمي) فتظهر دون تخزين.

## بدائل لتعبئة البيانات يدوياً
- استيراد فوري لمدينة: `npm run ingest -- --store=tamimi --city=makkah`
- كل المدن دفعة واحدة: `npm run ingest -- --store=tamimi`
- تجريبي (يثبت الوصول دون كتابة): أضِف `--dry-run`

## كيف تحصل على مفتاح Google Maps (Places API)

1. افتح **console.cloud.google.com** وسجّل الدخول بحساب جوجل.
2. أعلى الصفحة: **Select a project ← New Project** ← سمِّه (مثلاً `waffir`) ← **Create**.
3. فعّل الفوترة: القائمة الجانبية **Billing ← Link a billing account** (Places فيها رصيد مجاني شهري، لكن الفوترة مطلوبة للتفعيل).
4. فعّل الواجهة: **APIs & Services ← Library** ← ابحث عن **"Places API (New)"** ← **Enable**.
5. أنشئ المفتاح: **APIs & Services ← Credentials ← Create credentials ← API key** ← انسخ المفتاح.
6. (موصى به) **Restrict key ← API restrictions ← Places API (New)** لحصره على هذه الخدمة.
7. ضع المفتاح في Railway كمتغيّر `GOOGLE_MAPS_API_KEY` (أو أرسله لي).
8. من لوحة الأدمن ← تبويب **الاكتشاف** ← شغّل الاكتشاف لكل مدينة؛ تظهر متاجر المقاضي القريبة لتأكيدها.

## صدق تقني — مصادر المنتجات
- **التميمي**: واجهة JSON عامة متاحة → بنك ١٠ آلاف+ منتج عربي بصور (مؤتمت).
- **لولو / العثيم / الدانوب / النوري…**: مواقعها تحجب الوصول الآلي أو لا تتيح واجهة منتجات عامة
  (لولو يرجع 403). أسعارها تُجمَع عبر **مجلات العروض + الفواتير + التقارير**، وتُكتشَف فروعها عبر خرائط جوجل.
